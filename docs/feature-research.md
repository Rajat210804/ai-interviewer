# Interview preparation features

Reviewed on 20 October 2026. This is a small comparison of public project documentation, not an exhaustive review or a hands-on assessment of competing services.

Discovery: GitHub’s [AI interview](https://github.com/topics/ai-interview) and [mock interview](https://github.com/topics/mock-interview) directories.

| Project | Features described in its README | Relevance here |
| --- | --- | --- |
| [Go Interview Practice](https://github.com/RezaSi/go-interview-practice) | Structured challenges, progressive difficulty, hints and progress tracking | Give users focused exercises between full interviews. |
| [SimulateRecruitAI](https://github.com/Soumilgit/Soumilgit-AI-Interview-SAAS) | Saved interview history, custom practice sets and feedback by attempt | Let users return to feedback and review previous scores. |
| [AI Interview System](https://github.com/manthan89-py/AI-Interview-System) | Resume-based questions, voice interaction, adaptive follow-ups and complete transcripts | These are already covered by this app; retaining feedback makes repeat practice more useful. |

Direct requests to Yoodli, Huru, Final Round AI and Interview Warmup were blocked by the environment’s network policy, so their current capabilities were not verified.

## Changes selected

- An original, searchable library of 18 practice prompts across eight topics, with foundation/stretch levels, answer outlines, bookmarks and completion tracking.
- Explicit browser-local report saving, full text review/download, deletion controls and score history filtered by role, interview format and difficulty.

Question text and implementation were written for this project; no source code or question bank was copied. Library exercises are self-guided, with no AI grading. Report history stores only reports the user chooses to save, on the current browser profile, with a 20-report limit. Draft library answers are temporary. Score history shows AI estimates, not a standardised measurement of improvement.
